# Fern & Field Garden Co. — Good package sample

A sample website built by **Pontavia Consulting** to show what the **Good ($950)** website package includes.
Fern & Field Garden Co. is a made-up business in Ocala, Florida.

Live demo: https://pontavia-consulting.github.io/pontavia-sample-good/
Compare all three packages: https://pontavia-consulting.github.io/pontavia-samples/

A clean, fast, mobile-first brochure site: everything a local service business needs to look professional and get calls and quote requests.

## What's included

- 5 pages, built for phones first
- Quote request form with friendly validation
- Basic SEO: page titles and descriptions, social share tags, LocalBusiness structured data, sitemap.xml and robots.txt
- Click-to-call phone number and mailto link
- Accessible: keyboard navigation, visible focus, reduced-motion support

## Pages

- `index.html — home`
- `services.html — services with starting prices`
- `about.html — story and values`
- `faq.html — common questions`
- `contact.html — quote request form, hours, address`

## Notes

- Plain HTML, CSS and JavaScript. No build step, no framework, nothing to install.
- All plant pictures are SVG illustrations drawn by `assets/art.js`, so there are no stock photos to license.
- This is a front-end demo only: forms, bookings work in the browser but don't send or store anything on a server.
- To preview locally, open `index.html` in a browser, or run `python3 -m http.server` in this folder.
